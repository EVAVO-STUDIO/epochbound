# Epochbound

An original Godot 4.6.2 action RPG built with the look, pacing and tactile design discipline of a premium lost 1990s console adventure.

## Core pillars

- Multiple interconnected eras and evolving locations
- Player and loyal animal-companion gameplay
- Responsive real-time action combat
- Exploration, puzzles, secrets and environmental interaction
- Cinematic introductions, dialogue and story sequences
- Deep items, crafting, progression, quests and boss encounters
- Authentic pixel-art presentation with modern production tooling
- Original world, characters, narrative, artwork, music and terminology
